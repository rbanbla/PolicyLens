**2. 토론 방식**
쟁점은 사회자가 각 persona db를 확인하여 뽑는다 (각 agent가 쟁점을 여러개 뽑고 이에 대해 토론하면 좋을 것 같긴 하다...) 

-> 이 쟁점에 대해 각 persona가 한 줄로 자신의 입장을 주장하는 입론을 진행한다 

(표준적인 패널 토론 방식,독립적인 입론 진행 후 다른 추론 경로를 만들면 성능이 3.3% 증가한다는 Kaesberg et el 의 voting or consensus? decision making in muti- agent debate 연구 결과를 참고)

-사회자가 주도하여 토론을 진행한다 사회자의 역할은 다음과 같다
1) 앞선 발언 검토
2) 종료 여부 판단(새 쟁점. 근거가 나오지 않으면 중단)
3) 앞서 만든 DB를 통해 충돌 지점에 답할 이해관계자를 호출
4) 호출된 다른 이해관계자의 반론
5) 반론에서 새로운 충돌 지점이 등장하면 이를 저장 -> 토큰 이슈로 충돌 지점에 대한 토론은 구현X

- 반론 횟수를 무제한으로 하는 것을 원칙으로 한다/ 다만 발언이 3번 이상& 사용자가 토론 중단을 원할 시 중단한다/ 발언 총 합이 10회를 넘어가는 경우에도 사회자가 토론을 중단한다
