# 데모 진행

## 배포 전, 이 컴퓨터에서 확인

`./start.sh`를 실행하고 `http://127.0.0.1:8000/`을 연다. 이 주소는 로컬 확인용이다.

1. 첫 화면에서 PDF·DOCX·TXT를 올리거나 정책 원문을 붙여 넣는다.
2. 자동 요약과 원문 근거를 확인한다.
3. 문서를 확인하고 `쟁점과 수정 방향 보기`를 누르면 결과 화면에서 쟁점 탐색과 A·잠정 B 토론이 자동으로 시작된다. 공통 탐색 4회, A 11회, B 11회로 최대 26회 모델 호출이 발생한다. 실시간 실행에는 시간을 확보한다.
4. 즉시 보여줄 결과가 필요하면 `/demo/`의 2026-11-04 모의 정책 실호출 저장본을 연다. 이 화면은 새 문서를 분석한 결과가 아니며 모델을 다시 호출하지 않는다.

## 다른 기기에서 접속 · 무료 임시 주소

`./demo-online.sh`를 실행한다. 스크립트는 이 컴퓨터의 Django·PostgreSQL을 실행하고 Cloudflare Quick Tunnel의 임시 HTTPS 주소를 출력한다. 주소는 참석자에게 공유하고, 로그인 사용자명 `demo`와 비밀번호는 `.demo/credentials.txt`에서 확인한다. 컴퓨터, 네트워크, 실행 터미널이 켜져 있어야 하며 Ctrl+C로 주소가 종료된다. 새로 실행할 때 URL은 바뀔 수 있다.

외부 화면은 로컬 앱 전체를 보여 주므로 문서 업로드·요약·토론도 동작한다. 업로드한 정책과 결과는 Cloudflare HTTPS를 거쳐 이 컴퓨터로 전달되고 로컬 DB에 저장된다. 문서 확인 화면에서는 요약, 결과 화면에 들어가면 토론을 위해 로컬 서버가 설정된 모델 제공자로 입력을 보낸다. 공개 예시와 `/demo/`의 저장본을 보는 것만으로는 모델 호출이 없다. [경로와 운영 범위](LOCAL_ONLINE_DEMO.md)를 먼저 확인한다.

유료 상시 서버가 필요해지면 [Render 배포 설계](DEPLOYMENT.md)를 적용할 수 있다.
