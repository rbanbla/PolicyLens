# 청년 정책 수집 및 에이전트 사용 점검

점검일 2026-11-07. 범위는 전국 중앙정부·모든 지자체의 2026년 적용 청년 관련 세금·주거·대학·고용·혜택 정책이다.

## 수집 현황

국무조정실 공식 게시물의 첨부 3개를 확보했다. 중앙정부 시행계획 1권, 17개 시도 시행계획 17권, 중앙정부 5개 분야 과제카드 5권으로 총 23권·7,838쪽이다. ZIP 무결성과 모든 PDF의 SHA-256을 확인하고 원본 쪽 번호를 유지한 텍스트를 저장했다.

[국무조정실 원문 게시물](https://www.opm.go.kr/opm/info/youth_implementation.do?articleNo=162111&mode=view)

국세청·교육부·한국장학재단 원문 10건을 추가 확보했다. 국가장학금·학자금대출·희망사다리·국가근로와 세제 안내가 포함된다. 국세청 PDF 2건은 2025년판으로 2026 적용 여부를 확인해야 한다. HWP·HWPX와 HTML의 본문 추출·검수가 남아 있다. 중단된 복지 분야 작업의 출처 미확정 파일은 raw/unverified-benefits-2026-11-07에 보존했다.

수집 명세는 data/reviewed/collection_2026-11-07.jsonl, 묶음 해시는 national_bundle_2026-11-07.json에 있다. 신규 수집은 기존 documents.jsonl 및 Source와 별도로 보관하고 권리·기술 검수를 pending으로 기록했다.

전국 완전 수집은 미완료다. 17개 광역 시도 시행계획은 확보했으나 모든 기초지자체의 개별 모집·변경·정정 공고를 대조하지 못했다. 시행계획에 포함된 과제 수와 개별 공고 수는 다르다. 2026년 하반기 변경 공고, 지자체·대학별 장학금, 세제 개정사항을 추가 확인해야 한다.

## 실제 사용 경로

1. 원본은 data/raw, 처리본은 data/processed에 저장한다. 이 폴더에 저장하는 것만으로 검색에 연결되지는 않는다.
2. load_sources는 documents.jsonl의 기술·권리 pass와 external_send_ok를 검사해 Source 테이블에 적재한다. 내용 관문은 적재 조건에 포함하지 않는다. 검수 의견도 별도로 적재한다.
3. runner의 uses_sources가 단계·프롬프트·Source 존재 여부를 검사한다. analysis(역할 추출)와 issues(쟁점 정리)는 서버 검색을 하지 않는다. independent(역할 입장), debate(토론), final(최종 정리)에 검색 도구를 제공한다.
4. search_sources는 DB 문서를 메모리에 읽고 키워드로 순위를 계산한다. 결과는 최대 5쪽, 문서당 최대 2쪽이다. read_source는 한 쪽 전체를 반환한다. 벡터 검색이나 실시간 웹 검색은 없다.
5. 모델 결과의 sources에는 자료 ID·쪽·인용문·확인 내용을 저장한다. check_sources가 자료 접근과 인용문 존재를 검사하고 제목·기관·판본·URL을 실행 결과에 보존한다. 업로드 문서의 조항 인용은 별도로 검사한다.
6. 평가에서는 as_of 이전 정책만 검색하고 의견 자료를 제외한다. 업로드와 정규화 본문이 완전히 같은 서버 자료도 제외한다.

점검 당시 DB에는 Source 67건(정책 34·의견 33), 709쪽이 있다. 기존 서비스 실행 6건에서 검색 43회가 기록됐으나 외부 자료 인용은 0건이다. 저장 평가 파일 21개 중 서버 자료 사용 조건 12개에는 검색 59회·읽기 1회, 외부 인용 14개가 있다. 구버전 실행이 섞여 있어 현재 구현의 품질 지표로 일반화할 수 없다. 검색 성공만으로 답변에 근거가 활용됐다고 판단할 수 없다.

## 확인된 문제

- evaluate.py는 published_on만 검사하고 create_run과 analyze를 호출한다. external_send_ok=False 또는 권리 hold 문서를 평가 명령에 지정해도 외부 전송을 차단하는 검사가 없다. 평가 진입부에서 적재와 동일한 승인을 검사해야 한다.
- load_sources.py의 rows는 명세 파일이 없을 때 빈 목록을 반환한다. 이후 exclude(...).delete()가 실행되므로 파일 누락이 전체 서버 자료 삭제로 이어질 수 있다. 필수 명세 누락을 오류로 처리하고 적재·삭제를 하나의 트랜잭션으로 묶어야 한다.
- sources.py 검색은 본문에서 검색어를 찾은 경우에만 결과를 추가한다. 제목에만 일치하는 정책은 제목 가중치가 있어도 누락된다.
- search_sources의 record는 발췌 범위보다 넓은 한 쪽 전체를 opened에 기록한다. 따라서 반환된 발췌 밖의 문구도 check_sources를 통과할 수 있어 실제 열람 범위와 검증 범위가 다르다.
- runner.py의 search_first는 tool_choice=required를 사용한다. search_sources 대신 read_source만 호출해도 조건이 충족된다. 검색 필수라는 계약을 엄밀히 강제하지 않는다.

이번 작업은 수집 및 점검이며 위 코드 변경은 수행하지 않았다. 병렬 점검에서 읽기 전용 mock으로 문제 경로를 확인했고 실제 DB 쓰기·외부 모델 호출은 수행하지 않았다.

## 확대 적재 전 남은 작업

23권 중 중앙정부 개요 70쪽만 서비스의 분량 제한을 통과했다. 다른 22권은 80쪽 또는 10만 자를 넘는다. 과제 경계에 따라 분리하고 원본 ID·쪽 범위를 유지한 후 본문·표의 숫자와 적용 조건을 대조해야 한다. 단순히 제한을 높여 통째로 적재하면 매 검색마다 전체 자료를 스캔하는 비용도 커진다. 전체 원문 추출은 완료했으나 새 자료의 시각 검수·권리 승인·모델 이용 품질 검증은 남아 있다.
