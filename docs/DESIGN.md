# PolicyLens 화면과 모션

밝은 배경에 반투명 패널과 둥근 카드를 사용한다. 정책의 어려운 부분, 내 입장과의 충돌, 수정 방향이 먼저 읽히도록 정보량을 조절한다.

| 페이지 | 주요 정보 | 다음 행동 |
| --- | --- | --- |
| 1 문서 넣기 | 파일 업로드 또는 본문 입력 | 문서 분석 |
| 2 핵심 요약 | 문서 목적, 대표 이해관계자 2~3명과 영향 | 내 입장 선택 |
| 3 쟁점 찾기 | 쟁점 카드와 카드별 역할 한 줄 입장(채팅 없음) | 쟁점 토론 |
| 4 쟁점 토론 | 현재 쟁점 표시, 쟁점 구분선이 있는 사회자 진행 채팅, 하단 새 쟁점 정리 | 주의 조항 |
| 5 주의 조항 | 해당 조항, 내게 미치는 영향, 확인할 것, 역할별 의견서 | 새 문서 |

5페이지의 **두 결과 비교하기**는 상단 다섯 단계 밖의 비교 화면으로 이동한다. 두 결과는 같은 서식의 글이며 평가 저장 전에는 결과 A·B로만 표시한다. 두 결과는 같은 높이의 상자에 넣고 상자 안에서 스크롤한다.

## 채팅 동작

- 선택한 역할은 오른쪽 노란 말풍선, 다른 역할은 왼쪽 흰 말풍선에 표시한다. 이 정렬은 사용자가 확인했다.
- 이름과 ‘내 입장’ 표기로 색상 외에도 역할을 구분한다. AI의 역할 검토라는 점을 채팅 헤더에 표시한다.
- 모델 응답 대기 중에는 해당 역할 이름과 세 점 모션을 표시한다.
- 확정된 응답의 새 항목만 0.5초 동안 아래쪽·좌우에서 부드럽게 등장한다. 여러 항목은 0.2초 간격으로 추가한다.
- 생성된 전체 답변의 도착을 기준으로 표시한다. 토큰 단위 스트리밍은 사용하지 않는다.
- 발언의 이유를 최대 180자로 먼저 보여주며 전체 이유·제안·원문·우려는 펼쳐볼 수 있다.
- 기존 메시지를 교체하거나 새로고침 시 다시 애니메이션하지 않는다.
- 사용자가 대화 아래쪽에 있을 때만 새 발언을 따라 스크롤한다.
- 실패 시 저장된 말풍선을 유지하고 재시작 버튼을 보여준다.
- prefers-reduced-motion 설정에서는 등장·입력 중 모션을 끈다.

## 표현

- 주요 색은 파랑 `#3478f6`, 내 말풍선은 노랑 `#fff0ac`, 기본 배경은 `#f5f7fa`다.
- 유리 느낌의 패널은 반투명 흰색과 backdrop-filter를 사용한다.
- 5페이지 주의 표시는 높음을 빨간 테두리, 중간을 어두운 테두리로 구분한다.
- 데스크톱의 문서·역할 사이드바는 모바일에서 생략하고 대화에 집중한다.
- 원문, 의견서는 보조 정보로 펼쳐본다.
- 역할이 두 명이면 데스크톱에서 카드를 두 열로 표시한다.
- 상단 다섯 단계는 페이지 이동 메뉴다. 모델 실행 진행률은 숫자 막대로 표시하지 않는다.

## 구현 파일

- `server/static/app.css` — 디자인 토큰, 공통 컴포넌트, 반응형, 모션
- `server/static/review.js` — 작성 중 표시, 메시지 누적, 페이지별 자동 실행
- `server/static/interface.js` — 파일 드래그·선택과 업로드 상태
- `server/templates/` — 각 페이지, 채팅, 쟁점 카드, 주의 조항. 서버 자료 근거는 5페이지 카드 안의 `details.source`로 표시하며 2~4페이지에는 표시하지 않는다.
- `server/agents/progress.py` — 역할·페이지·메시지 ID를 UI에 연결

`previews/`의 화면에는 모의 문서와 모의 대화를 사용했고 서버 자료 표시 이전 화면이다.
